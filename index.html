A tokamak's magnetically confined plasma settles into a steady axisymmetric state described by the Grad–Shafranov equation. This page solves it directly, the way eigendrum solves the clamped-membrane eigenvalue problem for a drum shape — a real PDE, solved live with finite elements, not a canned animation.

The equation

∫∫ (1/R) ∇ψ·∇v  dR dZ  =  ∫∫ ( R p'(ψ) + FF'(ψ)/R ) v  dR dZ,      ψ = 0 on the boundary

ψ is the poloidal flux; its contours are the nested flux surfaces the plasma actually organizes itself along — the direct analog of eigendrum's nodal lines. p'(ψ) and FF'(ψ) are the pressure and toroidal-field profile functions that define a given steady state.

Fixed boundary, on purpose

The plasma boundary shape (elongation, triangularity) is imposed directly here, not computed self-consistently from external coil currents the way a real free-boundary equilibrium code (EFIT, CHEASE) would. That's the direct equivalent of eigendrum's clamped ψ = 0 edge condition, and it's the standard simplification used by fixed-boundary equilibrium solvers.

Why no eigensolver

Unlike the drum problem, this isn't an eigenvalue problem — it's a sequence of linear solves. p'(ψ) and FF'(ψ) depend on the unknown ψ itself, so the equation is nonlinear; it's solved by Picard (fixed-point) iteration: guess ψ, normalize it against the current magnetic-axis value, evaluate the profile functions, solve the resulting linear system, repeat until it stops changing. The stiffness matrix depends only on mesh geometry (not on ψ), so it's built once and reused every iteration — only the right-hand side changes — which is why a plain Jacobi-preconditioned conjugate gradient solver is enough, no direct factorization or eigensolver required.

Validation

For the special case where p' and FF' are both constant, a closed-form solution exists — the classical Solov'ev equilibrium (Solov'ev, 1968; see also Freidberg, Ideal Magnetohydrodynamics). This is the same role eigendrum's Bessel-function validation plays for the circular drum. Meshing the solver's mesh against that solution's own zero-flux contour and refining resolution gives clean second-order convergence: 

nRho   nNodes   L2 error
 8      385     6.3e-3
16     1537     1.8e-3   (3.6× reduction)
32     6145     4.8e-4   (3.6× reduction)
64    24577     1.3e-4   (3.7× reduction)

This validation is restricted to up-down symmetric (zero-triangularity) boundaries, which is what the closed form covers exactly. The shaped presets above (ITER-like, spherical tokamak) use the same validated solver and assembly code, just without an independent closed-form check of their own.

Units

Profile amplitudes (p₀, F₀ per steady-state preset) are solver-internal arbitrary units, chosen to make each preset's qualitative behavior clearly visible — not calibrated to real pressures or currents in pascals or amperes.

Live fuel burn

Press Play to run a real D-T burn calculation on top of the solved equilibrium: the standard 0D power-balance model used for reactor scoping (the same category of calculation behind the Lawson criterion), not a scripted animation. Reactivity <σv>(T) uses the Bosch & Hale (1992) parametrization; plasma volume is computed from the actual solved mesh (Pappus's theorem per triangle, treating R,Z as meters); each D-T reaction releases 17.6 MeV (3.5 MeV alpha + 14.1 MeV neutron). Deplete mode has no refueling — dn/dt = -<σv>n² — which has an exact closed-form solution n(t) = n₀/(1+n₀<σv>t), so power and cumulative energy are evaluated directly from elapsed time with no per-frame integration to accumulate error. Sustained mode refuels exactly as fast as fuel burns, holding density (and power) constant — real reactors need continuous pellet injection for exactly this reason, since natural burn-down timescales at these densities are tens of seconds to minutes, not hours.

Temperature and initial fuel density are illustrative, reactor-ballpark operating points assigned per steady-state preset (roughly 6–15 keV, ~0.6–1.1×10²⁰ m⁻³ — in ITER's target range), not derived from the solver's arbitrary-unit pressure profile amplitudes; the equilibrium shape itself stays the already-solved static one rather than being re-solved as fuel depletes. "Energy produced" is a running tally of fusion output, not a Q-factor netted against input heating power or confinement losses — that would need transport/confinement-time modeling this page doesn't attempt.

Not in this first pass

Safety-factor (q) profiles and rational-surface resonances — the direct fusion analog of "striking a resonant mode" — need flux-surface-averaged line integrals not yet implemented here. Stellarators are inherently three-dimensional and aren't handled by this page at all; they're a separate viewer built from equilibria precomputed offline (VMEC/DESC) rather than solved live in-browser — see the 3D stellarator viewer. The burn model doesn't re-solve the equilibrium as pressure drops, doesn't evolve temperature, and doesn't account for input heating power or energy confinement time.
